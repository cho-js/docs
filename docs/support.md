# Support

## Professional support

For help using CHO in your project, contact [info@chojs.io](mailto:info@chojs.io).

## Get help with an application

Start with the [runtime compatibility table](/reference/compatibility) to check your package, adapter and host. For a startup or dispatch failure, look up the error code in [error diagnostics](/reference/errors). When opening an issue, include the runtime and package versions, the smallest example that shows the problem, and the outcome you expected. [Contact the project](/contact)

## Support development

A focused bug report, a documentation correction or a contribution to the framework all help maintain CHO. The contribution guide explains how the project is organized. You can also sponsor the maintainer through GitHub. [Contribution guide](https://github.com/cho-js/cho/blob/main/CONTRIBUTING.md) · [GitHub Sponsors](https://github.com/sponsors/ziv)
