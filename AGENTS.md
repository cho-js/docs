# Documentation updates

Update `docs/reference/status.md` with each documentation update. Its current revision is the last **CHO framework commit** whose changes the documentation covers.

1. Read the current CHO revision from the status page. In the sibling `../cho` repository, compare that revision with the target revision before editing the guides.
2. After reviewing the changes and checking the affected examples, record the target's full SHA in the GitHub commit link at the top of the page. Use a short SHA and the commit subject as the link text.
3. Add a dated entry above the previous entries. Link the comparison between the previous and current CHO revisions, summarize the user-facing changes, link the affected guides and record the checks actually run.
4. For a documentation-only update, retain the covered CHO revision and record the guide changes under the update date. When several updates share a date, use the revision or topic to distinguish them.
